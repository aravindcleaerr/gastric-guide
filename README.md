# GutWise — Comprehensive Digestive Health Companion

A free, bilingual (English + Kannada) educational resource for understanding and managing digestive health conditions.

## Features

- **87+ Comprehensive Topics** covering digestive system, common conditions, diet, lifestyle, and more
- **Bilingual Support** — Full content in English and Kannada with language switching
- **Dark Mode** — Eye-friendly theme toggle with persistence
- **PWA Support** — Works offline, installable on mobile devices
- **Responsive Design** — Optimized for all screen sizes
- **No Tracking** — Privacy-first, no cookies or analytics
- **Accessible** — WCAG compliant with skip links and ARIA labels

## Topics Covered

- **Understanding Digestive Health** — Digestive system overview, gut microbiome, gut-brain connection
- **Acid & Reflux Conditions** — GERD, heartburn, silent reflux, hiatal hernia
- **Stomach Conditions** — Gastritis, peptic ulcers, H. pylori, gastroparesis
- **Intestinal Conditions** — IBS, IBD, Crohn's, ulcerative colitis, celiac disease
- **Common Issues** — Bloating, constipation, diarrhea, indigestion
- **Liver & Gallbladder** — Fatty liver, gallstones, hepatitis
- **Diet & Nutrition** — Gut-healthy diet, FODMAP, probiotics, Indian diet
- **Lifestyle** — Stress management, sleep, exercise, eating habits
- **Treatment** — Medications, natural remedies, Ayurvedic treatments
- **Emergencies** — GI emergencies, bleeding, food poisoning

## Technology Stack

- Pure HTML5, CSS3, JavaScript (no frameworks)
- Progressive Web App (PWA) with Service Worker
- Google Fonts (Noto Sans Kannada)
- SVG animations and illustrations
